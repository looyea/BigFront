# ES2015-2017：现代 JavaScript 的奠基三年

> 目标：把 **ES6(ES2015)** 一次性爆发的核心语法做一次「时间线式」收口（class / module / Promise / 解构 / Symbol / 迭代器 / Proxy 各归其位，并**指回前面已学的关卡**），再补齐常被忽略的 **ES2016（`includes`、`**`）** 与 **ES2017（async/await、`Object.values/entries`、字符串补位）**。学完本关，你能准确说出「某个语法到底是哪一年进来的」。

## 一、为什么要单列这三年

**ES2015 是 JavaScript 的分水岭**：在此之前是「玩具脚本」，在此之后才是「工程语言」。一次落地了：

| 类别 | ES2015 新增 | 本课程对应关卡 |
| --- | --- | --- |
| 声明 | `let` / `const` / 块级作用域 | [es-scope](es-scope.md) |
| 函数 | 箭头函数 / 默认参数 / rest | [es-arrow](es-arrow.md)、[es-params](es-params.md) |
| 数据结构 | `Map` / `Set` / `WeakMap` / `Symbol` | [es-map-set](es-map-set.md)、[es-symbol](es-symbol.md) |
| 对象/数组 | 解构、展开、计算属性、简写方法 | [es-destructure](es-destructure.md) |
| 类 | `class` / `extends` / `super` / getter-setter | 见本关第三节 |
| 模块 | `import` / `export` | [es-module](es-module.md) |
| 异步 | `Promise` / 生成器 `function*` | [es-promise](es-promise.md)、[es-iterator](es-iterator.md) |
| 元编程 | `Proxy` / `Reflect` | [es-proxy](es-proxy.md) |
| 字符串 | 模板字面量 / 标签模板 / Unicode `u` | [es-string-unicode](es-string-unicode.md) |

> **一句话**：本课程 L1~L8 讲的就是 ES2015 的家底，L9 从这里开始按「年份」再走一遍，帮你建立**时间坐标**。

## 二、ES2015 之外的「边角」补齐

前八关已把主干吃透，这里只收那些**没单独成关、却常被问**的点。

### 1. 数字与数学
```js
Number.isNaN(NaN);       // true（旧的 global isNaN('x') 会误判为 true）
Number.isInteger(3.0);   // true；3.5 → false
Number.EPSILON;          // 2.22e-16，浮点比较容差
Math.trunc(-3.9);        // -3（截断小数）
Math.sign(-5);           // -1
Math.cbrt(27);           // 3
2 ** 10;                 // ⚠️ 这是 ES2016 的幂运算符，不是 ES2015！
```

### 2. 二进制 / 八进制字面量
```js
0b1010 === 10;   // true  二进制
0o17 === 15;     // true  八进制（注意不是旧的 017）
```

## 三、`class`：糖，但不只是糖

`class` 常被说成「`function` 的语法糖」，但有**三处本质不同**，面试高频：

```js
class Animal {
  static count = 0;          // 静态字段（真·私有静态要 ES2022 的 #count）
  #sound;                    // ⚠️ 私有字段是 ES2022，此处仅示意
  name;                      // 实例字段（ES2022 才标准化，见 es-2022 关）
  constructor(name) { this.name = name; Animal.count++; }
  speak() { return `${this.name} makes a sound`; }   // 方法挂在**原型**上
  get displayName() { return this.name.toUpperCase(); }
  static create(n) { return new Animal(n); }         // 静态方法
}
class Dog extends Animal {
  constructor(n) { super(n); }                        // 必须先 super()
  speak() { return `${super.speak()} and barks`; }
}
```

**与手写构造函数的差异（务必背下）**：
1. **类声明不提升后可用**——`class` 有自己的 **TDZ**（呼应 [es-hoisting](es-hoisting.md)），在定义前引用抛 `ReferenceError`；
2. **方法不可枚举**——`Object.keys(Dog.prototype)` 为空，而手写原型方法可枚举；
3. **所有代码运行在严格模式**——`this` 不自动指向全局。

**`new.target`（ES2015）**：在构造函数里得知是被 `new` 哪个类调用的，用于「抽象基类不可实例化」：
```js
class Shape { constructor() { if (new.target === Shape) throw new Error('抽象类'); } }
```

## 四、ES2016（ES7）：只加了两样，但都常用

```js
// 1) 数组 includes —— 比 indexOf 能判断 NaN
[NaN, 1, 2].includes(NaN);      // true
[NaN].indexOf(NaN) === -1;      // -1（NaN !== NaN）

// 2) 幂运算符 ** 与 **=
2 ** 3;                          // 8
2 ** -1;                         // 0.5
// ⚠️ 一元负号与 ** 混用需括号：(-2) ** 2 合法；-2 ** 2 是 SyntaxError
let n = 2; n **= 4;              // n = 16
```

就这两项——所以 ES2016 常被并讲，但 `includes` 判 `NaN` 这个细节每年都有人踩。

## 五、ES2017（ES8）：async/await 元年

**最重要：`async/await`**（把 [es-promise](es-promise.md) 的链式改写为同步风格）：
```js
async function load(id) {
  try {
    const res = await fetch(`/api/u/${id}`);
    return await res.json();
  } catch (e) {
    console.error(e);            // 错误处理终于像样了
  }
}
```

其它四项：
```js
Object.values({ a: 1, b: 2 });                    // [1, 2]
Object.entries({ a: 1, b: 2 });                   // [['a',1],['b',2]]
'5'.padStart(3, '0');                             // '005'（还有 padEnd）
'ab'.repeat(2);                                   // 'abab'（repeat 实为 ES2015）
Object.getOwnPropertyDescriptors(obj);            // 含 getter/setter 的完整描述符
function f(a, b,) {}                              // 函数参数尾逗号（ES2017 起允许）
```

**`Object.entries` vs `for...in`**：entries 只取**自有可枚举**且**返回键值对数组**，`for...in` 会**遍历原型链**——这是常见 bug 源。

## 🚀 部署预告（本关点到，细节在 L10）

1. **class 的降级**：Babel 早期把 `class` 编译成 `_createClass` 辅助函数（约几百字节/类）；现代 target（ES2015+）**原生保留不转**——Vite `build.target` 默认 `es2020` 时，class/箭头/module 全部原样输出。
2. **async/await 降级成本最高**：转 ES5 需要 `regenerator-runtime`（≈5KB gzipped）——**这是 polyfill 体积大头**。能定 ES2017+ 就别降级。
3. **`Object.values/entries`、`padStart`、`includes`** 都是**运行时方法**，需 core-js 按需 polyfill（各约 200-400B），Babel `useBuiltIns:'usage'` 自动注入。
4. **幂运算符 `**`** 是纯语法，编译成 `Math.pow`，零运行时成本。
5. **browserslist 建议**：若你的最低端是「现代浏览器 + Node 18+」，target 直接 `es2017` 起步，能省掉 regenerator 这 5KB。详见 [es-build](es-build.md)。

**你现在只需记住**：**ES2015 给了 JS 骨架，ES2017 给了 JS 异步的「同步写法」**——而降级时 `async/await` 是最贵的那块，优先原生。
