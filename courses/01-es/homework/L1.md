# L1 作业 · 变量与作用域

> 完成下列题目后，回到关卡页勾选「作业已完成」。**答案请写在 `solutions.md`（自行新建）或直接口述验证**，本题集随课程包一起提交到你的 GitHub。

## 基础题
1. 不使用查资料，写出 `var`、`let`、`const` 各一条最本质的区别。
2. 预测输出并说明理由：
   ```js
   const list = [1, 2, 3];
   list.push(4);
   list = [5];
   ```
   哪一行会报错？为什么？

## 进阶题
3. 把下面代码改成输出 `0 1 2` 的两种不同方法（一种用 `let`，一种用 IIFE）：
   ```js
   for (var i = 0; i < 3; i++) {
     setTimeout(() => console.log(i), 100);
   }
   ```

## 挑战题
4. 阅读并解释这段"计数器"为什么能记住上次的值（闭包雏形）：
   ```js
   function makeCounter() {
     let count = 0;
     return () => ++count;
   }
   const c = makeCounter();
   console.log(c(), c(), c()); // ?
   ```
