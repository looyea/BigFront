# 面试题 · 解构与展开运算符

1. **`{...obj}` 是深拷贝还是浅拷贝？**
   **浅拷贝**。嵌套对象仍是同一引用。深拷贝用 `structuredClone(obj)`（现代浏览器/Node 17+）或递归。

2. **展开运算符会带上原型链上的属性吗？**
   不会。spread 只复制**自身可枚举**属性。想带原型：`Object.assign({}, obj)` 同样只自身可枚举；`JSON.parse(JSON.stringify())` 更会丢函数/undefined/Symbol。

3. **下面代码 x 的值是？**
   ```js
   const { a: x = 10 } = {};
   const { a: y = 10 } = { a: undefined };
   const { a: z = 10 } = { a: null };
   ```
   - x=10, y=10, **z=null**。默认值仅在 `undefined` 时生效，null 不触发默认值——这是常见坑。

4. **数组解构和对象解构的底层原理？**
   - 对象解构：按属性名取值 `{ x } = obj` → `obj.x`。
   - 数组解构：按**迭代器协议**（Symbol.iterator）逐个 next()，所以 Set/Map/生成器都能数组解构。

5. **如何用解构交换两个变量？**
   ```js
   [a, b] = [b, a];
   ```
   原理：右侧先构造临时数组完成取值，再左侧赋值。

6. **rest 与 spread 分别在什么位置？**
   - rest（收集）：赋值/参数**左侧**，如 `const {a, ...rest} = obj`、`function f(...args)`。
   - spread（展开）：**右侧/表达式**位置，如 `f(...arr)`、`[...a, ...b]`、`{...o1, ...o2}`。

7. **对象合并谁优先？**`{...a, ...b}` 与 `{...b, ...a}` 有何区别？
   后展开的**同名属性覆盖先展开的**。所以顺序决定优先级。
