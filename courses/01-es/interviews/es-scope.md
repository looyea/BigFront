# 面试题 · let / const 与块级作用域

> 面试官最爱从「三件套」问起。答不清 var 的坑，基本就止步了。

1. **var、let、const 有什么区别？**（必答）
   - var：函数作用域、存在变量提升（hoisting）、可重复声明、挂到 window。
   - let/const：块级作用域、同作用域内重复声明会 SyntaxError、不挂 window。
   - const：绑定不可变（对象/数组的**内容**仍可变），必须在声明时初始化。

2. **什么是暂时性死区（TDZ）？为什么会有？**
   块内 let/const 声明前的位置对该变量不可访问；访问就 ReferenceError。设计上是为了强制「先声明后使用」，杜绝 var 那种「用了还不知道自己已被隐式提升」的坑。

3. **下面代码打印什么？**
   ```js
   for (var i = 0; i < 3; i++) setTimeout(() => console.log(i));
   for (let j = 0; j < 3; j++) setTimeout(() => console.log(j));
   ```
   - 第一组：`3 3 3`（共享同一个函数作用域的 i）
   - 第二组：`0 1 2`（每次迭代都有独立的 j 绑定，JS 规范专门为此做了 per-iteration binding）

4. **const 声明的对象能被修改吗？如何让它真的不可变？**
   - 能被修改（const 只锁绑定，不锁值）。
   - `Object.freeze(obj)` 只能浅冻结；深冻结要递归，或用结构化克隆 + 不可变数据结构库（如 immer produce）。

5. **闭包是什么？举一个你实际工作里用闭包解决过的问题。**
   函数 + 其词法环境的组合。典型用法：模块私有变量、防抖/节流、柯里化、React Hook 内部状态捕获。

6. **(() => {})() 和 (() => {})(); 为什么前者需要括号包起来？**
   表达式语句位置以 `function` 开头会被解析成函数声明。IIFE 必须让解析器认为它是一个**表达式**，所以用 `(function(){})()` 或 `!function(){}()` 等强制表达式化。

7. **加练**：说说你如何在项目里避免全局污染（IIFE、ESM、命名空间对象、WeakMap 私有字段…）。
