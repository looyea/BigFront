# React L2 · 路由、状态与工程

> 🎯 目标：了解 react-router、状态方案与 React 生态的整体版图

## 一、路由

社区主流是 `react-router`（`<Routes>` / `<Route>` / `useNavigate`）。

## 二、状态管理版图

小用 useState、共享用 Context、复杂用 Zustand / Redux Toolkit / 数据层用 React Query。按需选择，别过度设计。

## 三、生态现实

纯 React SPA 常用于后台/交互密集应用；需要 SSR/SEO 时直接上 **Next.js**（本学院后续包）。
