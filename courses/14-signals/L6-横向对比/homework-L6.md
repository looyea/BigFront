# L6 阶段作业：横向对比

> 覆盖：sig-vs-streams / sig-mutability / sig-scenarios
> 判分：Bug 每题 3 分、手写每题 7 分、场景题 20 分、简答每题 5 分、挑战 +10 分（基分 100）

## 一、Bug 猎杀（10 小题，每题指出唯一错误并给出修法）

**Bug 1**（stream 当状态用）
```ts
const price$ = ws$.pipe(shareReplay(1));
// 组件挂载时：price$.subscribe(p => render(p))
// 工具函数里：price$.value  // ??? 拿不到
```
指出『流的当下值是补丁』在此的显形，给出海关式重构（一行 subscribe 的挪法+新变量选型）。

**Bug 2**（signal 当事件队列用）
通知中心用 `lastEvent = signal(null)`，effect 里读它弹 toast——连续两条相同文案的通知只弹一次，快速连发还丢中间条。指出 signal 覆盖语义与事件『一条都不能少』的冲突，改回什么抽象。

**Bug 3**（不可变上游混进可变兄弟）
父组件 state 不可变，但从 MobX store 抓了个 observable 对象混进 props 传给 `React.memo` 子组件——子组件收到『看起来变了』的 props 却不重渲。指出引用身份证在两家世界的失效点，给出境协议修法。

**Bug 4**（immer 冻结误会）
`const snap = produce(state, d => { d.a = 1 })`，随后第三方库就地改了 `snap.b.c`，历史快照跟着变、撤销栈失真。指出『不可变产物≠自动冻结』，给两层防线（配置+出境拷贝）。

**Bug 5**（deps 里的可变对象）
```jsx
useEffect(() => { sync(config) }, [config]);   // config 来自某处 getState() 的可变单例
```
config 内容变了 effect 不重跑。指出浅比较判定依据，给两种修法并注明各自付出的税。

**Bug 6**（switch 语义手搓漏取消）
signals 版搜索只做了 `latest === q` 的结果丢弃，Network 面板显示所有旧请求仍然发完。指出『丢弃』与『取消』的差别，补上取消需要什么原语。

**Bug 7**（debounce 与 effect 清理打架）
给 signal 版搜索加 `lodash.debounce` 包 setTimeout，effect 重跑时旧 debounce 实例没 cancel——旧定时器延迟触发打了新值。指出手写时间阀门与自动清理链的挂接缺口，给修法。

**Bug 8**（顺手塞进全局 store）
下拉框开合状态被写进全局 Zustand（当初『顺手放的』），组件在两个页面复用时开关状态互相串门。按决策树判这条的碗籍错在哪，重写归属并说明『谁同时读』答辩怎么补。

**Bug 9**（服务端数据二传手）
useQuery 拿到 profile 后 `useEffect(() => setUser(data), [data])` 复制进 store，切换组织后个别页面显示旧 profile。指出双事实源三宗罪在此的显形路径，组件侧正确的读法。

**Bug 10**（URL 与 store 双向同步回环）
筛选器把 URL 参数写进 Zustand 又反向同步回 URL，两个 effect 互相触发、history 堆满 replace 记录。指出双源回环成因，定一个方向（谁是源谁是镜）并给防回环写法。

## 二、手写题（5 题）

**手写 1**：搜索去抖三件套（debounce+distinct+作废取消）分别写：① RxJS 管道版；② signal+手写 latest+AbortController 版。并排贴代码，各加三行注释指出『这一行在另一个版本里对应什么』。

**手写 2**：给『万行表格改一格』画两张通知链路图（MobX 路径投递 vs Zustand 广播比较），标出每一步的成本归属（复制税/通知税/比较税各落在哪步）。

**手写 3**：写 40 行内的『事件→状态海关』mini 模块：`createBridge(rxLikeSource)` 暴露 `signal`（当下值）+`events`（原序列）两个出口，演示下游只从 signal 读数、审计走 events。

**手写 4**：默写决策树主干（四问三岔），在叶子旁标注五碗归属；用它现场裁一遍：向导步骤索引/播放器音量/未读数缓存/文章列表/拖拽坐标。

**手写 5**：把本团队（或 12/13 包练习项目）的全局状态开一张『状态户口表』：现状归属/应然归属/错住红字三处——按规范五条给整改排序。

## 三、场景题（1 题，20 分）

你加入一个 3 年历史的中型 React 后台（20 万行）： Redux+MobX+Context+散装模块级单例并存，同一份用户信息有四个读点三个版本，撤销功能只在编辑器模块有且常年有 bug。给出重构战役方案：① 审计与分碗（五碗+户口表方法，如何在不停产的前提下盘点）；② 目标架构（分工矩阵落地版：谁管哪段、边界协议、URL/Query/域模型/UI 态四线画法）；③ 迁移路线（双写桥/绞杀榕/按 feature 切，每步的验证安全网与回滚点）；④ 规范固化（目录+lint+PR 模板三件套怎么写才能活下去）。

## 四、简答题（3 题）

**简答 1**：一句话分别回答：signal 生态处理异步竞态的主流策略是什么？RxJS 的？两者在『海关』这个词下如何会师？

**简答 2**：『可变把成本付在协作纪律，不可变把成本付在语法学习』——各给一个本包出现过的具体事故作证据。
