# sig-roadmap 面试题精选

> 共 15 题。A 类=原理机制；B 类=实战排坑；C 类=横向对比；D 类=场景设计。这门课『之后』的问题：趋势判断、学习策略、以及把课程知识转成面试现场的长期弹药。

### 1. (C) 面试收尾常见问『你觉得状态管理未来会怎么发展』——给一个不显得在猜彩票的回答结构。

**来源**：转述自本关 §三三线合流的回答框架化

结构=**区分『已发生的趋势』与『待复验的判断』**：已发生（可当事实说）——Query 模型成共识、框架数据层上移、signal 图元跨库同构；待复验（标明触发条件说）——『库时代收缩协议时代展开』（证伪信号：提案长期停 stage2 且各框架适配层退化）、『细粒度回潮』（证伪信号：React 编译器把抽象税问题自动化解，Signal 需求被编译层吸收）。加分动作：每条判断挂一个**按年复验的具体观察项**（如『明年看 React 是否引入官方 signal 原语』）——面试官听到『我的判断带复验计划』时，这道题从考知识变成了考思维品质。

### 2. (A) §二给 Zustand 留的方向②说『理解 React 派订阅模型后，Jotai/Redux/Zustand 是同一张图的三种投影』——展开讲这句话。

**来源**：转述自本关 §二方向②与 za-core/externals-store 机制的合拢

共同原图=外部 store + `useSyncExternalStore`：一个可订阅源、一个 getSnapshot、React 负责并发安全订阅（撕裂防护）。三投影的差只在**源的切法与快照的粒度**：Redux=单树+reducer+中间件洋葱，Jotai=原子森林+依赖推导，Zustand=多小树+selector 自选切面。深读入口推荐 `useSyncExternalStoreWithSelector` 的 memo 层（react-redux 内部件）——它把『快照稳定化』这个三家都暗办的环节摊开成显式函数。到达这个视角的标志：你看『该选哪家』的问题自动降维成『我的数据形状适合哪种切法』——这正是判据链吃透的样子。

### 3. (D) 团队新人问『我该按什么顺序深入这四强』——用本包知识给一条 8 周路径并解释为什么是这个序。

**来源**：转述自本关 §二方向地图的教学序重组

序：**Zustand 两周**（唯一无前置心智的库，先建『外部 store 三件套』手感+getState 旁路）→ **TC39 signals 两周**（图元最小模型，直接读 Preact signal 源码百行级——internals §二毕业后的首个源码档）→ **RxJS 三周**（范式和前三者正交，最难所以放中段有备而来：先学 marble 再学 operator 顺序不能反）→ **MobX 一周**（此时它的『魔法』你已能拆成订阅图元+Proxy+调度三层，一周是查缺补漏不是初学）。为什么不是课包序：课程序按认知逻辑（从简单声明到复杂编排），自学序按**心智迁移成本**——把正交最难项隔离成独立攻坚段。加分句：全程配 14 包 homework 自检清单做阶段验收。

### 4. (C) AsyncGenerator 挑战 RxJS『管过程』席位（§二留的活棋）——给一个今天就能做出的判断：什么新项目我会直接选 AsyncGenerator？

**来源**：转述自本关 §二 RxJS 方向②的趋势应用题

选 AsyncGenerator 的画像：**顺序性强、组合简单、无时间轴需求**的过程——SSE 流式文本渲染（for-await 天然表达『一块块来』）、分页数据聚合、MCP/stdio 协议客户端。不选的信号一出现就该引 RxJS：**需要横向组合**（两流合并/竞速/开关——merge/race/switchMap 在 async 世界要手写状态机）与**时间轴算子**（debounce/throttle/window——async 世界里全是手写定时器的坑）。判据本质：AsyncGenerator 赢在顺序语法糖（对读者友好），输在并发与时间的原语缺失——**『过程越接近一条直线，async 迭代器越够用；过程一开始分叉汇合，就要流的代数』**。这题考的是海关链的预判性使用。

### 5. (B) 你按本包学了判据链，面试里说了句『没有免税范式，只有免税位置不同』，面试官追问『那位置到底指什么』——给三个层次的回答。

**来源**：转述自本关 §一两税链与其被追问时的展开预案

三层：① **代码位置**——可变税集中在『协作面』（action 规范、谁都能改对象的团队纪律），不可变税集中在『表达面』（selector/更新语法的每次书写）；写单兵项目时表达面天天交、协作面几乎不交，所以 solo 开发者偏爱不可变。② **生命周期位置**——项目早期形状未定，不可变的探索成本低（重构=改声明）；后期稳定，可变的维护成本低（少一层拷贝语法），**同一项目在 18 个月的不同位置上两种税的汇率不同**。③ **生态位置**——React 生态（引用比较三铆钉）把不可变税打到骨折，Solid/Vue 生态把可变税降到接近零（响应式内置）——位置不只是项目内的，还是技术栈里的。被追问能给出三层=把口诀讲成了活模型。

### 6. (A) §四清单要求『能解释 glitch 是推送序与依赖序不同流的必然』——口头答一版 60 秒的，并指出『两阶段』解法付什么税。

**来源**：转述自本关 §四清单第 3 项（internals q6 的结业口试版）

60 秒版：菱形 a→b、a→c、b+c→d，写 a 后系统必须通知 b、c 再通知 d——但 forEach 直推按**注册顺序**走：b 跑完立刻级联 d，此刻 c 还没更新，d 读到半新半旧的世界，等 c 跑完 d 再跑一遍。**只要执行序不等于依赖偏序，中间帧必然存在**——这是图的性质不是代码的疏忽，所以叫必然。解法=两阶段：先沿订阅集标脏不执行（收集本轮全部变更），再按依赖深度序统一执行。税：**每轮一次全可达子图遍历+排序**（工业用维护的链表/版本号近似拓扑序摊薄），外加 batch 语义的时序复杂度（读新值跑旧通知的悖论要文档化）。能顺口报出『税』这个字，说明学的不是结论是权衡。

### 7. (D) 公司技术雷达要写状态管理条目：Adopt/Trial/Assess/Hold 四档，把本包内容映射进去——给一版雷达并说明每条的『进出条件』。

**来源**：转述自本关 §三趋势判断的组织化输出（技术雷达体裁）

Adopt：**Zustand（客户端共享态）**、**框架数据层/Query 模型**——进出条件：出现跨标签页持久化需求或 SSR 时降 Trial 重审单例债。Trial：**TC39 signals 形态**（新小型 SPA 试点）——升 Adopt 条件=提案 stage 3+且试点框架有官方适配层；Hold：**再引入 Redux/saga**（存量只维护不新增，migrate 关给路线）、**新自造总线**（跨边协议违规件）。Assess：**AsyncGenerator 流式场景**、React Compiler 动向——每季度看一眼是否冲击现有档位。雷达的灵魂是**每格的进出条件都是可观测事件**（§三『按年复验』的组织版）——面试官看到条件句而非形容词，就知道这份雷达会真的更新。

### 8. (C) 结课口诀六条（海关/两税/五碗/信号廉价/面板 GUI/先测量）如果只能往简历写一条，选哪条、怎么写成不被追问倒的版本？

**来源**：转述自本关 §四清单最后一项的落地策略

选『先测量再吵架』——唯一一条**自带证据属性**的口诀（其余五条是结论句，写在简历上等于邀请站队追问）。写法要挂产物：『主导四范式对照实验（受控剧本+核心/胶水分栏+帧时间裁判），输出区段级选型判据文档被 X 项目采纳』——追问方向立刻变成你的主场（实验协议怎么立、哪个预测翻车了），而不是口诀背诵。风险控制：另外五条写进**面试口头表达**而非简历文本——它们是判断力展品，文本上易被读成口号。元规则一条：**口诀只有配上你的仪器与案例才不是梗，简历文本是全世界最缺上下文的地方**。

### 9. (A) §三说『提案改变库与框架的谈判地位』——把这句政治学比喻翻译成机制语言，并给一个可能让它落空的机制。

**来源**：转述自本关 §三第 1 线的去比喻化考察

机制语言：提案若定稿，图元 API（signal/computed/effect 的构造与订阅语义）跨库通用——库的差异化空间被压缩进**调度实现**（批处理、惰性、粒度）与**周边设施**（devtools、持久化、SSR），框架则获得用官方图元重写内部响应式的合法路径（Angular 已在做）。谈判地位=差异定价权：API 不再稀缺后，库只能靠实现与生态定价。落空机制一个就够：**提案永远停在『有 API 无实现性能保证』的定位**——若 spec 允许实现间性能差两个数量级（比如不约束惰性），各框架仍会保留私有一等公民实现，提案沦为兼容性摆设，谈判桌根本没摆起来。判断句：标准化收益取决于它敢不敢对性能语义立约。

### 10. (B) 自检清单全勾了，三个月后你在真实项目里『还是』选错了库——用本包的框架给『选错』做尸检，什么算真错、什么算假错？

**来源**：转述自本关 §四清单与其自我定位（让你离开它）的实弹应用

尸检先分真伪：**假错**=形状判对了但世界动了（当时『无高频区』的判断基于当时的需求单，三个月后产品加了拖拽）——判据链不预测需求，只保证你在需求变时**第一个发现**（复盘问『变更发生时我有没有用形状语言识别它』）；**真错**=测量缺席（没写预测直接抄了上季度的结论）、或形状读反（把服务端缓存当客户端事实——L8 三问没过就立项）、或**用冠军句决策**（『因为团队都会 Zustand』不是形状归因，是迁移成本的诚实版——若你把它包装成技术判断就是真错）。清单全勾不等于不犯错，等于**每错必可归因到清单哪一格没执行**——这就是结课水平的定义。

### 11. (C) 把本包与 12/13 包（工程化/现代框架 internals）的关系说清：它依赖谁、给谁让路、谁离不开它？

**来源**：转述自本关 §四与全仓包际网的收拢题（sig-map 期末版）

依赖它上游：**13 包 internals** 提供了依赖图语言（glitch/拓扑/惰性全套判据的出生地）与『先测量再吵架』的仪器文化；**12 包工程化**给了 CI 预算/lint 制度（sig-size 的 size-limit、perf 的回归断言都挂在那套设施上）。让路给下游：**框架内置响应式**（Solid/Vue/Angular signal）与**框架数据层**——capstone 报告结论句『区段级选型』意味着当框架能力覆盖更多区段，第三方库叙事会进一步收缩。离不开它的：任何**跨框架的架构评审场景**（选型/迁移/共存题）——12/13 包教的是『这套系统怎么运转』，14 包教的是『几套系统摆桌上怎么判』，这是仓库里唯一以『对比决策』为体的包，也是最容易被框架更新淘汰却以判据形式保值的包。

### 12. (D) 一年后回看，如果 Fine-Grained Reactivity 论文那套版本号机制进了四大库的『标配』，本包哪几关的含金量会升值、哪几关会折旧？

**来源**：转述自本关 §二方向①与趋势线的组合推演

升值：**sig-internals**（版本号/惰性校验是验尸单第 4、5 条的工业正解，懂 §三清单的人才能读懂新调度器）、**sig-perf**（细粒度普及后，性能诊断从组件层下沉到表达式层，MutationObserver 取证术变通用语）、**sig-vs-streams**（海关链在『图元统一』后更值钱——API 同质化时代，唯一差异是范式归属）。折旧：四库各自的 **API 记忆**（za-core/mobx-core/rx-basics 的语法细节，由判据层知识接棒）、**sig-migrate 的 Redux 篇**（存量技术随时间自然退潮，但迁移方法论不退）。答题结构比内容分重要：**『升值=判据层、折旧=表面层』**——这个预测本身就在演示本包教的思维方式，说对说错反而次要。

### 13. (A) 课程说结课标志是『知道下一步往哪走』——给一个自检方法：怎么测自己是『有地图』还是『只背了地图』？

**来源**：转述自本关 §四清单的元测试（判据链是否内化的操作化）

测法=**造一个地图上没有的新需求**（例：WebGPU 渲染循环里每帧更新 2 万个实体属性，需要跨 worker 同步），走完整流程：三条形状特征能否自拟（高频/大粒度/跨界）、四强各判一句贴合度、预言哪个维度会最先崩（大概率是通知风暴或序列化墙）、给出一个地图外候选（SharedArrayBuffer+自写环形缓冲）并说清引它付什么新税。能流畅走完=判据链已内化（它的工作方式正是『没有先例时从形状重建结论』）；卡在第一步=背了地图——特征清单背得再熟，新需求上提不出来就是没懂。此法适用于任何技术学习：学完一个体系，拿一个它没覆盖过的真实难题做毕业考。

### 14. (C) 四种人才画像（业务 CRUD 主力/中台组件库作者/疑难杂症猎手/架构谈判者）各自的『本包必修三关』组合是什么？

**来源**：转述自本关 §二进阶方向的读者分层版（sig-map 人群轴的期末答案）

业务 CRUD 主力：**sig-server（数据归位）+ za-patterns（订阅面纪律）+ sig-auth（需求形状初体验）**——他们最缺的是边界协议不是知识广度；中台作者：**sig-size（三本账替用户算）+ internals（API 背后的调度语言）+ sig-scenarios（替接入方做决策树）**——组件库的状态 API 是给客户立法，必须懂判据链；猎手：**sig-perf + sig-debug 双关（四坑四问三问已是主力武器库）+ internals q13 的 MobX 三层拆解（读源码前哨）**；谈判者：**sig-migrate（桥与对拍）+ sig-server §四终态判断 + §三趋势三线的复验计划**——谈判桌上赢在『我的判断带证伪条件』。这题的隐性答案：**全包没有一关对四类人都同等必修——判据链用到自己身上，就是按人分型配药**。

### 15. (D) 收官：五年后你的技术栈面目全非，本包哪五样东西是你打算带进坟的？给一份『陪葬清单』并说明挑选标准。

**来源**：转述自本关全篇的终极自反（课程存在的最后答辩）

清单：① **读形状再选代价**这个动词（一切的母体）；② **三问审计法**（图书馆/传家宝判据，任何『往共享容器塞东西』的评审都过它）；③ **两税汇率观**（没有免税、位置定税率、汇率会变——防一切范式信仰）；④ **带预测的测量纪律**（写预测→diff→归因——这条不止用于状态管理，是全部技术判断的防身术）；⑤ **口诀要配仪器**的警觉（对自己也一样：每背出一句顺口的结论，先问它在我的项目里应验了几次）。挑选标准一条：**五年后仍然『做对事情』所依赖的，而不是『谈论事情』所用的**——四库 API 属于后者，六条口诀不配仪器也属于后者。这门课到这儿就交还给你了。
