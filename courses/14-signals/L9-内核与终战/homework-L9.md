# L9 阶段作业：内核与终战

> 覆盖：sig-internals / sig-capstone / sig-roadmap
> 判分：Bug 每题 3 分、手写每题 7 分、场景题 20 分、简答每题 5 分、挑战 +10 分（基分 100）

## 一、Bug 猎杀（10 小题，每题指出唯一错误并给出修法）

**Bug 1**（finally 命门）
mini-signal 的 createComputed 里写 `CURRENT = compute; compute.value = fn(); CURRENT = prev;`——某次 fn 抛异常后，全站订阅爆炸。指出病名与修法，说明『全世界都在替谁订阅』。

**Bug 2**（旧边幽灵）
`compute = () => flag() ? a() : b()`，flag 翻 false 后 a.set 仍触发 compute 重跑。指出订阅图维护漏了哪一步，给删除式重建修法，并说明工业版用什么省掉这步开销。

**Bug 3**（缝合态实锤）
`a.set(1); b.set(2)`，依赖 a+b 的 effect 跑了两次且第一次数值不一致。两问：这是 bug 还是特性？『批处理』与『glitch-free』分别治这案子的哪一半？

**Bug 4**（无门环）
effect 里 `count.set(count() + 1)`，页面卡死栈溢出。给检测层与调度层两种工业修法，说明各自适用场景（应用代码 vs 高频写入源）。

**Bug 5**（实验偷换）
capstone 对照中 RxJS 版以『流范式不适合持久化』为由跳过 localStorage 需求。违反协议哪条？这个动作会怎样污染其余三栏数据？

**Bug 6**（量纲混比）
报告里写『Solid DOM 写 12 次 vs Zustand commit 3400 次，Solid 快 283 倍』。指出两处计算错误（量纲与结论词），给合法的呈现方式。

**Bug 7**（胶水隐身）
选型汇报 PPT：『核心行数 MobX 210 / RxJS 230，差距不大』。指出分栏缺失造成的两处低估，说明『显性胶水收代码量、隐性胶水收运行时』各对应这两个库的什么。

**Bug 8**（预测污染）
同学测前预测『Zustand 拖拽一定最快』，测出 22fps 后当场改用例（拖拽距离改 50px）重测到满意为止。违反哪条纪律？正确处置是什么？

**Bug 9**（伪冠军句）
简历写『通过四库对比实验证明 Zustand 是最优状态管理方案』。按 §五结论纪律改写这句话（保留实验事实、换掉结论形态）。

**Bug 10**（趋势当事实）
周报写『signals 提案已定稿，明年各库将统一 API』。用 §三『已发生 vs 待复验』框架指出分类错误，给出带复验条件的正确写法。

## 二、手写题（5 题）

**手写 1**：不看课件默写 mini-signal 的 createSignal（含 Object.is 闸门与读挂边），再口头补全 computed 的压栈出栈——写不出的部分回 §一§二重读后重默，直到一次通过。

**手写 2**：给 mini-signal 加 §三第 1 条批处理：实现 batch(fn)，用『两次 set 只跑一遍 effect』的断言验证；再写 batch 内读 signal 返回新值还是旧值的实验并注释你的结论与理由。

**手写 3**：三行 untracked：实现并构造一个『调试日志读不打边』的用例（effect 里 console.log 用 untracked 包裹，验证该 signal 更新不再因日志建边而触发 effect）。

**手写 4**：capstone 速食版：只搭拖拽段剧本（pointermove→set→渲染），至少完成 Zustand 与 Solid（或 preact signals+React）两版的渲染次数/DOM 写次数测量，附你测前的预测值与 diff 说明。

**手写 5**：给自己写一份『判据链卡片』：海关/两税/五碗三链各两句（判据句+一个你自己项目里的实例），装进口袋——下次架构评审带出去用一次，记录战果或翻车。

## 三、场景题（1 题，20 分）

你面试的公司在评估『把三个产品线的前端状态技术栈收敛』：A 线 React+Redux 老仓 40 万行、B 线 Vue3 已用组合式 API、C 线新 React 项目想用 MobX 做工单域模型。CTO 只问你要一页纸建议。用全包视角写这一页：① 三条线各自的形状诊断（各引一条判据链）；② 『收敛』二字哪些部分该支持、哪些部分该劝退（给区分标准）；③ A 线方案（迁移三件套+哪些可以永久不迁）；④ C 线方案（支持引 MobX 但要配哪三条契约纪律）；⑤ 一个全公司统一的东西——不是库，是________（填空并论证）；⑥ 每条判断附一个『什么信号出现时我会改口』的复验条件。

## 四、简答题（3 题）

**简答 1**：『信号廉价、一致性昂贵』——用 internals 验尸单三条各一句话解释这句话的前半与后半。

**简答 2**：§三说『库时代收缩、协议时代展开』——用一句话分别给『收缩』与『展开』各一个正在发生的证据。

**简答 3**：结课清单九格里，哪一格你当前最虚？给它的『离开本包后第一个复训动作』（不超过 30 分钟的具体事）。

## 五、挑战题 🏆（+10 分）

毕业双件套：① 挑一个你真实用过的开源库/内部组件，用 internals §三的图纸（订阅集+闸门+通知方式三栏）拆解它的状态机制，写半页——若它没有订阅集，论证它为什么不需要；② 找一个判据链没覆盖的新需求（interview q13 的 WebGPU 题或自造），走完『三形状特征→四强判词→一个地图外候选→它的新税』四步写成 200 字。两项各 5 分，评审标准只有一条：**有没有出现『因为/所以』而不是『听说/一般认为』**。
